# Лабораторна 8 — ORM зв’язки

Окремий Flask-застосунок для SQLAlchemy 2.0: зв’язок User–Post один-до-багатьох і Post–Tag багато-до-багатьох.

## Запуск

Перейди в каталог lab8, встанови залежності, застосуй міграції та запусти Flask:

    cd lab8
    pip install -r requirements.txt
    flask db upgrade
    flask run

Міграції вже створені. Повторно flask db init запускати не потрібно.

## Маршрути

- /post — список публікацій з авторами й тегами;
- /post/create, /post/<id>, /post/<id>/update, /post/<id>/delete — CRUD постів;
- /users/create, /users — автори навчальної бази;
- /tags/create — створення тегів;
- форма поста завантажує авторів і теги з БД та дозволяє вибрати кілька тегів;
- сторінка поста показує його теги.

## Оптимізація запитів

Створи п’ять постів, двох авторів і три теги. Признач кожному посту автора; один пост повинен мати кілька тегів, а один тег має повторюватися в різних постах.

Запусти python scripts/compare_loading.py. Скрипт виконає базовий і eager-loading варіанти в окремих ORM-сесіях, надрукує записи й порахує SELECT. Оптимізований запит використовує joinedload(Post.author) та selectinload(Post.tags).
